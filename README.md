## About

Sosaykey は Wails (Go) で作成する、Markdown ファイルの内容を表示するデスクトップアプリケーションである。
フロントエンドの JavaScript は vanilla に限定し必要最小限の記述のみ、ロジックは可能な限り Go 側に実装する。

## 名称の由来

Markdown -> MD -> Genesis -> 創世記 -> "So, say 'key'!!" -> Sosaykey

普段だとこれくらいこねくり回すと何かいい感じのひらめきが得られるのだが、何も浮かばなかったので「もうこれでいいや」という事で。


## 基本機能
- メニューから選択したファイル、またはドラッグ&ドロップされたファイルを Markdown として解釈し、変換結果を表示する
- 現在開いているファイルを記憶し、明示的なリロード操作で再解釈できる
 - メニュー操作
 - Ctrl + R

## Markdown パース方針
- Markdown の方言差に柔軟に対応・判断できるよう、既存ライブラリは使用せず Go 側で自前実装する
- 表示結果の解釈方針を切り替えられるようにする (この目的の為、読み込んだ md ファイルの内容はメモリー内に保持し、形式が変わった場合に再度パースする)
  - Sosaykey のデフォルト
  - GitHub で表示した場合の挙動に近づける
  - GitLab で表示した場合の挙動に近づける
  - IntelliJ IDEA / VS Code 等のエディタでの表示に近づける
  - など

## 非 Markdown 入力の扱い
- 選択された対象が Markdown として妥当でない場合でも、セキュリティ上問題がない限りは「Markdown として解釈した場合の結果」を表示する
- バッファオーバーラン等の脆弱性につながる挙動は許容しない (攻撃的な内容の可能性がある場合のみ対処する)
- 内容が崩れて表示されること自体は、アプリケーションとして想定された挙動とする

## クリップボードコピー機能
- 表示された内容の選択部分をコピー可能
- コピーされる形式は以下の通り
  - 余計なメタ情報を含まないプレインテキスト
  - 選択範囲に相当する Markdown 表現
- Ctrl + A, Ctrl + C などの標準ショートカットに対応
- 選択操作自体は WebView 標準の挙動を利用できる見込みだが、コピー時の挙動は独自に制御する (Markdown 表現のプレインテキストをコピーする為)

## 選択範囲に対応する Markdown 表現が曖昧な場合の方針
- 要素の途中が選択されており「相当部分」の判断が難しい場合
  - 適切な判断が容易に可能なら、それを行う
  - 判断が困難な場合は、足りなくなるのを避け、要素全体を含める方向に倒す

## ファイル変更の追跡と再読み込み
- 開いているファイルの変更を監視する
- 原文が更新された場合、ウィンドウ隅の変更ステータス表示を変更し「最新ではない」ことを通知する

### 再読み込みモード
デフォルト挙動:
- 変更は追跡するが、自動では再読み込みしない

オプション設定で以下を選択可能:
- 変更検知時に確認ダイアログを表示するモード
- 確認なしで即座に再読み込みするモード

#### 再読み込み確認ダイアログの表示条件
- 変更検知時に確認ダイアログを表示するモードで変更を検知した場合
- ウィンドウ隅の変更ステータス表示をクリックした場合

## UI オプション
